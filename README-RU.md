# Universo Platformo Angular

Реализация Universo Platformo / Universo MMOOMM / Universo Kiberplano на базе Angular (фронтенд) и Gin (бэкенд) с использованием TypeScript и Go.

## 🏗️ Архитектура: Модульный монорепозиторий на основе пакетов

**КРИТИЧЕСКИ ВАЖНО**: Этот проект следует **строгой модульной архитектуре**, где ВСЯ функциональность реализована в виде независимых пакетов в директории `packages/`.

### Структура пакетов

```
packages/
├── universo-types/          # Общие TypeScript типы
├── universo-utils/          # Общие утилиты
├── universo-api-client/     # Библиотеки API клиентов
├── universo-i18n/          # Интернационализация
├── universo-rest-docs/     # Документация API
├── universo-ng-components/ # Общие Angular компоненты
├── auth-frt/               # Аутентификация фронтенд (Angular)
├── auth-srv/               # Аутентификация бэкенд (Go/Gin)
└── {feature}-frt/          # Фронтенды функций
└── {feature}-srv/          # Бэкенды функций
```

### Почему модульная архитектура?

Этот проект спроектирован для **постепенной эволюции от монорепозитория к мультирепозиторию**:

1. **Фаза 1 (Текущая)**: Все пакеты как workspace-пакеты в монорепозитории
2. **Фаза 2 (Будущее)**: Зрелые пакеты извлекаются в отдельные репозитории
3. **Фаза 3 (Долгосрочная)**: Остаются только базовые пакеты, функции независимы

**Каждый пакет ДОЛЖЕН быть спроектирован как независимый от репозитория с первого дня.**

## 🛠️ Технологический стек

- **Фронтенд**: Angular 17+ с TypeScript
- **UI библиотека**: Angular Material
- **Бэкенд**: Фреймворк Gin с Go 1.20+
- **База данных**: Supabase (на основе PostgreSQL)
- **Аутентификация**: Go-based middleware с коннектором Supabase
- **Менеджер пакетов**: PNPM с workspaces
- **Инструмент сборки**: Nx для оркестрации монорепозитория
- **Тестирование**: Jest (фронтенд), Go testing (бэкенд), Playwright (E2E)
- **i18n**: ngx-translate

## 📦 Соглашения о пакетах

Каждый пакет следует этим правилам:

- **Именование**: `{feature}-frt` (фронтенд) или `{feature}-srv` (бэкенд)
- **Структура**: Каждый пакет содержит директорию `base/` с основной реализацией
- **Общие пакеты**: Используют префикс `universo-*`
- **Документация**: Каждый пакет имеет двуязычный README (английский и русский)
- **Независимость**: Пакеты предоставляют четко определенные интерфейсы для межпакетного взаимодействия

## 🚀 Начало работы

### Предварительные требования

- Node.js 18+
- Go 1.20+
- PNPM 8+

### Установка

```bash
# Установите PNPM, если еще не установлен
npm install -g pnpm

# Установите зависимости
pnpm install

# Соберите все пакеты
pnpm build

# Запустите серверы разработки
pnpm dev
```

## ⚠️ Критические правила

**ЗАПРЕЩЕННЫЕ ПРАКТИКИ** (будут отклонены при проверке кода):
- ❌ Создание кода функций вне директории `packages/`
