# start-frt — Стартовые страницы (Angular)

> **Пакет**: `@universo/start-frt`  
> **Технология**: Angular 17+ (Standalone Components)  
> **Статус**: Активная разработка

## Обзор

Angular-модуль стартовых страниц. Предоставляет стартовую страницу для гостей (неавторизованных пользователей) и страницу онбординга для авторизованных пользователей. Аналог `start-frontend` из `universo-platformo-react`.

## Ключевые возможности

- **StartPageComponent**: Умный маршрутизатор между гостевым и авторизованным видом
- **GuestStartPageComponent**: Лендинг с призывом к действию (переход к `/auth`)
- **AuthenticatedStartPageComponent**: Мастер онбординга (Проекты → Кампании → Кластеры)
- **StartFooterComponent**: Общий подвал с контактами и юридическими ссылками

## Использование

```typescript
import { StartPageComponent } from '@universo/start-frt';

// В маршрутах
{ path: '', component: StartPageComponent }
```

## Страница для гостей

Отображает:
- Герой-секция с заголовком и кнопкой "Get Started" → `/auth`
- Карточки функций платформы
- Подвал

## Страница для авторизованных

Отображает:
- Мастер онбординга в 3 шага (если не завершён)
- Экран завершения (если онбординг уже пройден)
