# auth-srv — Бэкенд аутентификации (Go/Gin)

> **Пакет**: `universo-platformo/auth-srv`  
> **Технология**: Go/Gin  
> **Статус**: Активная разработка

## Обзор

Go/Gin бэкенд-сервис аутентификации, обеспечивающий сессионную аутентификацию через Supabase. Этот пакет является аналогом `auth-backend` из `universo-platformo-react`, переписанным на Go/Gin вместо Node.js/Express.

## Информация о пакете

| Атрибут | Значение |
|---------|---------|
| Язык | Go 1.21+ |
| Фреймворк | Gin |
| Провайдер аутентификации | Supabase |
| Тип сессий | Cookie (серверные) |
| Порт (по умолчанию) | 3101 |

## Ключевые возможности

- **Интеграция с Supabase**: Аутентификация email/пароль через Supabase Auth API
- **Управление сессиями**: Безопасные серверные сессии в cookie (7 дней)
- **CSRF-защита**: Токен-защита для изменяющих состояние запросов
- **Обновление токенов**: Автоматическое обновление Supabase-токенов до истечения
- **Поддержка CORS**: Настраиваемый CORS для Angular-фронтенда

## API-эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/api/v1/auth/csrf` | Получить CSRF-токен |
| `POST` | `/api/v1/auth/login` | Вход по email/паролю |
| `POST` | `/api/v1/auth/register` | Регистрация аккаунта |
| `GET` | `/api/v1/auth/me` | Текущий пользователь |
| `POST` | `/api/v1/auth/logout` | Выход |
| `GET` | `/health` | Проверка работоспособности |

## Установка и запуск

```bash
cp .env.example .env
# Укажите ваши Supabase-данные в .env

go run cmd/server/main.go
```
